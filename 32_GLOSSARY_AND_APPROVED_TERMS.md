# 32_GLOSSARY_AND_APPROVED_TERMS

Status: Reference  
Authority level: Tier 3  
Primary scope: Stable terminology

## Approved core terms
- Daimon: one-soul guide from World Soul
- Garment: sphere-substance worn by the soul
- Metaxy: connective medium, not level
- Plateau: actual stopping place, not loose metaphor
- Gnosis: noetic threshold condition, not generic spiritual knowledge
- Hēdonē: pleasure Plateau, not same as Eros
- Eros: desire / beauty Plateau and wider cosmic desire depending on context
- Nous: Divine Intellect
- The One: beyond being
- Anankē, Philotimia, Phantasia, Eidōlon: keep Greek names

## Mandatory distinction pairs
- Hēdonē ≠ Eros
- elemental residue ≠ garment attachment
- threshold ≠ sphere proper
- Plateau ≠ test environment
- transformed release ≠ returned release
- knowing ≠ being
- matter is real ≠ matter is all
- school ≠ courtroom
- Hermetic ≠ Gnostic

## Naming rules
- use Greek Plateau names
- use canonical being names exactly
- do not casually invent alt names for Governors or Plateaus

## Imported vocabulary rule
Avoid terms like:
- astral plane
- spirit guide
- archon
- karma as punishment

unless a character is misnaming something.

## Compact Retrieval Block
- canonical Greek names only
- keep core distinction pairs sharp
- glossary stabilizes terms for generation
