# 00_CANON_AUTHORITY_AND_FILE_ARCHITECTURE

Status: Canonical control file  
Authority level: Highest operational reference  
Primary use: Read first before generation, revision, or verification

## Purpose

This file defines:
- what outranks what
- what counts as hard canon
- what counts as style law
- what counts as anthology architecture
- how conflicts are resolved
- how the Claude Project file set is organized for reliable retrieval

This is not a prompt.  
This is the control layer for the anthology project.

## Canon Priority

### Tier 1: Cosmological hard canon
Controls:
- metaphysical facts
- soul mechanics
- garments
- daimons
- Governors
- Plateaus
- realm order
- reincarnation rules
- higher-realm rules

Rule: if a story beat or style preference contradicts Tier 1, Tier 1 wins.

### Tier 2: Voice and style canon
Controls:
- tone
- pacing
- chaptering
- prose law
- humour density
- anti-lecture rules
- technical story specs

Rule: Tier 2 decides *how* canon is rendered. It may not change canon fact.

### Tier 3: Anthology architecture and operating files
Controls:
- story map
- movement design
- recurring interludes
- character protocol
- continuity tracking
- verification workflow

Rule: Tier 3 operationalizes Tier 1 and Tier 2. It does not override them.

### Tier 4: Story-specific packets
Controls:
- one individual story's local execution

Rule: Tier 4 obeys Tiers 1 to 3 at all times.

## Conflict Resolution

- If the issue is factual, cosmology wins.
- If the issue is tonal or formal, style wins.
- If the issue is structural but not contradictory, anthology architecture decides.
- Facts follow cosmology.
- Writing follows style.
- Story packets obey both.

## Non-Negotiable Anthology Truths

- The project is Hermetic Neoplatonism, not Gnosticism.
- The cosmos is a school, not a prison.
- Matter is real and sacred, not evil or fake.
- Incarnation is opportunity, not punishment.
- Fate is real below. Freedom is real through nous.
- There are no adversarial cosmic jailers.
- Governors test. They do not persecute.
- Plateaus are stopping places, not punishments.
- Reincarnation is opportunity, not karmic sentencing.
- Philosophy enters through character experience.
- Comedy and truth are allies.
- Open questions remain open.

## File Categories

### Hard Canon
Must remain stable across all 36 stories.

### Binding Style Constraints
Mandatory writing rules that are not setting facts.

### Architecture Guidance
Series structure and generation workflow.

### Flexible Space
Permitted variation that does not break canon.

### Open Questions
Deliberate unknowns. Claude must not invent definitive answers here.

## Retrieval Design Rules

- One main job per file.
- Strong filenames.
- Stable literal headings.
- Repeat the most load-bearing truths in multiple relevant files.
- Keep reference files separate from generation files whenever possible.
- Avoid poetic headings that hide the topic.
- Use a metadata block at the top of every file.

## Metadata Standard

```md
# FILE TITLE

Status: Canonical / Binding / Reference / Index / Story-Specific
Authority level: Tier 1 / Tier 2 / Tier 3 / Tier 4
Primary scope: [exact topic]
Used during: Generation / Revision / Verification / All
Conflicts resolved by: [higher authority file if relevant]
Do not use for: [topics this file does not govern]
```

## Master Verification Questions

Before accepting any story, confirm:
1. Did it violate hard cosmology?
2. Did it violate binding style rules?
3. Did it become accidentally Gnostic, punitive, or contemptuous?
4. Did it lecture instead of dramatize?
5. Did it preserve school-not-prison?
6. Did it preserve no-adversarial-beings?
7. Did it preserve current counts, names, and role distinctions?
8. Did it remain aligned with 3 Movements and ~9,000 words?
9. Did it keep comedy alive without trivializing pain?

## Compact Retrieval Block

- Hermetic not Gnostic

- no adversarial jailers
